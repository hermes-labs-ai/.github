# hermes-labs-ai/.github

This is the organization-level meta repository for [Hermes Labs](https://hermes-labs.ai). It holds the org profile that renders on the organization landing page at [github.com/hermes-labs-ai](https://github.com/hermes-labs-ai), plus shared community-health defaults for the org's repositories.

- **Org profile (the public landing page):** [`profile/README.md`](./profile/README.md)
- **Hermes Labs** is an independent AI-reliability lab building the audit, runtime, and evidence layer for production LLM systems.

Edit `profile/README.md` to change what visitors see on the organization page.
