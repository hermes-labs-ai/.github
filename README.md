# hermes-labs-ai/.github

This is the organization-level meta repository for [Hermes Labs](https://hermes-labs.ai).
It holds the public profile that renders at
[github.com/hermes-labs-ai](https://github.com/hermes-labs-ai), the shared community-health
defaults for the organization, and the checks that keep its open-source tool and research links
aligned with their public sources.

- **Org profile (the public landing page):** [`profile/README.md`](./profile/README.md)
- **Phone cloud work menu:** [`CLOUD.md`](./CLOUD.md)
- **Hermes Labs** is an AI reliability engineering studio for product and engineering teams
  shipping production agents and LLM applications.

Edit `profile/README.md` to change what visitors see on the organization page.

## Shared defaults

GitHub applies these to every repository in the organization that does not publish its own
version of the file.

- [`SECURITY.md`](./SECURITY.md) — how to report a vulnerability privately
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — contribution expectations
- [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) — Contributor Covenant 2.1
- [`SUPPORT.md`](./SUPPORT.md) — where questions, bugs, and commercial requests go
- [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE) — bug and feature forms
- [`.github/PULL_REQUEST_TEMPLATE.md`](./.github/PULL_REQUEST_TEMPLATE.md)
