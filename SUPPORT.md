# Support

This is the organization-wide default support policy for [Hermes Labs](https://hermes-labs.ai).
A repository that publishes its own `SUPPORT.md` overrides this file.

Route your question to the right place:

## Usage questions and reproducible bugs → GitHub issues

Open an issue in the repository in question. Include the version, your platform, the exact command
you ran, what you expected, and what happened. A minimal reproduction gets a much faster answer.

## Security vulnerabilities → private report

Do **not** open a public issue. See [`SECURITY.md`](SECURITY.md) and email
**roli@hermes-labs.ai**.

## Commercial reliability engineering → direct contact

For technical audits, runtime hardening, evaluation design, or evidence work on a production
system, email **roli@hermes-labs.ai** or use the contact form at
[hermes-labs.ai](https://hermes-labs.ai/#contact).

## What support is and is not

These are open-source engineering tools maintained alongside client work. Issues are read and
triaged, but response times are not contractual and there is no hosted or paid support tier for
the open-source packages.

Each tool documents an **evidence boundary** — what it does not establish. If your question is
whether a clean result proves a system is safe or correct, start with that section of the
repository's README.
